# Software directory editorial data and images

The initial selection in `app/lib/software.py` was reviewed on 2026-09-10 using
the official sites linked from each entry. Keep descriptions factual and update
platforms, status and license classification when upstream support changes.
`active` means ongoing development; `maintenance` means fixes without active
feature development; `inactive` means development has stopped. Do not infer
status from a single missed release. The directory supports proprietary software,
but this initial selection contains four open-source projects.

Image sources (unmodified upstream artwork):
- JOSM: https://josm.openstreetmap.de/svn/trunk/nodist/images/logo/header.png
- StreetComplete: https://streetcomplete.app/res/favicon.svg
- Organic Maps: https://organicmaps.app/images/screenshots/hiking.jpg
- QGIS: https://qgis.org/img/footlogo.svg

Names and visual identities belong to their respective projects. The images
identify the showcased applications, without implying endorsement. Source and
licensing references: JOSM https://josm.openstreetmap.de/wiki/License,
StreetComplete https://github.com/streetcomplete/StreetComplete/blob/master/LICENSE,
Organic Maps https://github.com/organicmaps/organicmaps/blob/master/LICENSE,
QGIS https://qgis.org/resources/hub/marketing/ and https://qgis.org/license/.

Filters use ordinary GET parameters and work without JavaScript. Unknown filter
values normalize to All. To add entries, supply a local image and translated
description, cite the upstream source and check each declared platform.
